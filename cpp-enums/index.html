1. DERIVATION: STORAGE COST
DEFINING THE EXPERIMENT:
enum class E_INT        { A, B }; // default int
enum class E_CHAR : char{ A, B }; // explicit char
E_INT  i = E_INT::A;
E_CHAR c = E_CHAR::A;
⬇ COMPILATION (clang++ -S) ⬇
OBSERVING INSTRUCTION WIDTH:
movl $0, -4(%rbp)   # int uses movl (4 bytes)
movb $0, -5(%rbp)   # char uses movb (1 byte)
INFERENCE:
Instruction width matches data type size.
∴ char saves 75% memory.
2. DERIVATION: I/O COST
DEFINING THE EXPERIMENT:
cout << (int)i;   // integer output
cout << (char)c;  // character output
⬇ COMPILATION (clang++ -S) ⬇
OBSERVING FUNCTION CALLS:
call operator<<(int)   # Complex formatting logic
call operator<<(char)  # Simple buffer write
INFERENCE:
Integer IO requires formatting overhead.
∴ char IO is faster (3.5x measured).
3. DERIVATION: CPU EXECUTION (THE SURPRISE)
PATH A: INT LOGIC
int val = (cond) ? 1 : 0;
⬇ ASM ⬇
cmovnel %ecx, %eax
# 1 Instruction
# 0 Branches
# 0 Spills
PATH B: CHAR LOGIC
char val = (cond) ? 'A' : 'B';
⬇ ASM ⬇
jne .LBB1_2
movb -5(%rbp), %al
# Multiple Instructions
# 1 Branch (Hazard)
# 4 Spills (Memory)
INFERENCE:
x86-64 lacks 8-bit Conditional Move (`cmovb`).
∴ Compiler must use Branch + Stack for `char`.
∴ `int` is faster for pure logic.
