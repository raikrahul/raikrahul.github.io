02. The Investigation

ANALYSIS: ASSEMBLY, PIPELINE, & STACK SPILLS

[A] THE CMOV vs BRANCH AXIOM

Axiom: x86-64 has `cmovne` for 32-bit registers but NO conditional move for 8-bit registers.

INT (32-bit)
cmovnel %ecx, %eax
> Single Instruction
> No Branch
CHAR (8-bit)
jne .LBB4_6
> BRANCH REQUIRED
> Pipeline Stalls (3-5 cycles)

[B] STACK SPILL PROOF

Compiler runs out of 8-bit capable registers (limited to al, bl, cl, dl), causing stack thrashing.

INT (REGISTERS)0 SPILLS
CHAR (STACK)4 SPILLS
# CHAR ENPATHY (Slow Path)
movb %dl, -42(%rbp)  # Spill to stack
cmpl $0, %ecx        # Compare
movb %al, -41(%rbp)  # Spill to stack
jne .LBB4_6          # Branch
movb -42(%rbp), %al  # Reload from stack

[C] TIMELINE OF DISCOVERY

STEP 1Run benchmark with cout
RESULTCHAR wins (3.5x)
STEP 2Remove cout (Pure Move)
RESULTINT wins (17%)
STEP 3ASM Analysis
FINDINGMissing 8-bit CMOV

[D] CONCLUSION

1. Context is Everything: Storage size != Speed.
2. Instruction Set Matters: Missing 8-bit CMOV hurts `char`.
3. Final Verdict: Use `char` for storage/IO, `int` for raw logic.
