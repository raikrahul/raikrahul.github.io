02. The Investigation [ASM]

ANALYSIS: ASSEMBLY, PIPELINE, & STACK SPILLS

[A] INSTRUCTION SET LIMITATION

INT (32-bit)
cmovnel %ecx, %eax
> NO BRANCH
CHAR (8-bit)
jne .LBB4_6
> BRANCH REQUIRED

[B] STACK THRASHING (-O0)

INT (REGISTERS)0 SPILLS
CHAR (STACK)4 SPILLS
# CHAR SLOW PATH
movb %dl, -42(%rbp)  # Spill
cmpl $0, %ecx        # Cmp
movb %al, -41(%rbp)  # Spill
jne .LBB4_6          # Branch
movb -42(%rbp), %al  # Reload

[C] ROOT CAUSE

1. MISSING INSTRUCTION:
   x86-64 has cmovnel (32-bit)
   x86-64 has NO cmovb (8-bit)

2. CONSEQUENCE:
   Compiler must use BRANCH (jne) for char
   
3. COST:
   Branch Misprediction = ~5 cycles
   Stack Spill/Reload   = Memory Latency
